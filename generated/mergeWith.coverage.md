## Specialization and reachability

`REFILL` is removed: the initial pending set is empty, no retained transition adds an input, and the validator rejects fabricated pending subscriptions. With zero other inputs, `COMPLETE-WAIT` is also removed. The default profile has six retained rules; the one-input profile has five. Bounded state exploration separately checks all live-input subsets for one through four total inputs using representative next/error payloads. It does not exhaustively explore the complete 0–32-other-input domain or arbitrary payloads and scheduling.

## Evidence boundaries

Generation consistency, reachable-rule witnesses, and runtime conformance are separate checks. Finite witnesses are not proof of all executions. Normal final-input cleanup ordering is checked using an ordered teardown log, not inferred from same-frame marble timestamps. Array conversion, synchronous subscription-time production/cancellation and pipeline cancellation are explicitly native-only. The historical [Session 15 evidence](../evidence/SESSION-15.md) is retained; the corrective result belongs to the [refinement ledger](../evidence/REFINEMENT-MERGEWITH.md).
