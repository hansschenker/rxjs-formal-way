## Traceability

All eleven canonical rules are reached through legal model prefixes. Obligations link to M02C-RX-01..15 in tests/m02c-rxjs.test.mjs; later cases test ties, native source lifetimes and pipeline interactions. The clock-aware runner rejects inconsistent envelope timestamps. Stale/early/foreign firings are illegal model events, not RxJS API behavior.

The differential domain is durations {0,2,4}, binary words length 0..4, three spacings, complete/error/cancel endings, three final offsets and two insertion strategies. It observes value/time, source lifecycle and logical scheduler commands. Scheduler generations identify scheduled invocations, not physical Action objects or host timer IDs.

```sh
npm ci --ignore-scripts

```

Record the exact tested commit, run ID and inspected job log before asserting runtime acceptance. Finite coverage is not a universal proof. Inline zero-delay scheduling, clock rollback, arbitrary reentry, throwing observers/finalizers, unsafe/fractional durations, lossless payload serialization and a production timer interpreter remain outside this checkpoint.
